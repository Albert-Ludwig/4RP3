# 4RP3 — WELL-E Research

Hi, I am **Johnson Haoran Ji**, an undergraduate Mechatronics Engineering student at McMaster University.

This repository documents my 4RP3 research with **Prof. Matthew Giamou** in McMaster University's [Autonomous Robotics and Convex Optimization (ARCO) Lab](https://arcolab.mcmaster.ca/). The repository contains study notes, research papers, and project materials related to this work.
